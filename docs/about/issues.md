# Issues

Reporting an issue?
Here are the following things to keep in mind.

## What qualifies as an issue

While not an exhaustive list of valid issues, this list is generally enough to cover the most common issues.

- A single typo or a set of typos
- Mistakes with formatting
- Bugs with navigation, search, etc.
- Potentially incorrect information

## Preparing your report

Your report of the issue does not have to follow strict formatting or language guidelines.
Please note however that the following information may be required:

- **Details about your device(s):** For technical bugs and issues.
- **Specific link to the page:** For typos, misspellings, broken formatting.
- **Official confirmation:** For information that is no longer correct.

## Locations to report an issue

### Codeberg

You can report the issue you are having with the guide using the Issues tab on Codeberg.

[:simple-codeberg: Make an issue on Codeberg](https://codeberg.org/DessertSource/dessert-brickadia-guide/issues/new){ .md-button .md-button--primary }

Making an issue on the repository requires a Codeberg account.
However, if you already have a GitHub account, you can "sign in with GitHub" on Codeberg, which creates a new account.
