This guide is DessertSource's personal take on an all-purpose guide that's
geared towards making users understand the mechanics of [Brickadia](https://brickadia.com),
a sandbox game.

The site for this guide is built with [Zensical](https://zensical.org/), a
static site generator that can be used with [GitHub Pages](https://docs.github.com/en/pages)
to host documentation. This allows for a heightened focus on documentation and
less time spent on setting up or tuning the backend.
